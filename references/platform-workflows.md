# 平台工作流

## 小红书

1. 从 `/discovery/item/<id>` 或 `/explore/<id>` 提取 24 位十六进制笔记 ID。
2. 优先读取页面 `window.__INITIAL_STATE__` 中的笔记对象；分享链接里的 `xsec_token` 只用于本次访问，不写入 Skill。
3. 保存标题、描述、类型、互动数、博主昵称、封面、视频时长和媒体链接。
4. 图文笔记按原始顺序下载全部图片；视频笔记下载封面和主视频。
5. 优先下载 `mediaV2.video.subtitles` 中的中文字幕。将 SRT/VTT 去时间戳后整理为段落；没有字幕再用本地语音识别。
6. OCR 封面和正文图片，但只保留正文未覆盖的有效信息。
7. 分享 URL、媒体 URL 可能过期；知识库必须保留本地媒体，不能只依赖远程地址。

常见失败：未登录页面没有目标笔记对象、风控页、链接签名过期、视频流存在多种编码。此时优先复用用户已登录浏览器，不能绕过验证。

## 微信公众号文章

1. 支持 `https://mp.weixin.qq.com/s/<id>` 公开文章。
2. 读取 `#activity-name`、`#js_name`、`#js_author_name_text`、发布时间、`og:image` 与 `#js_content`。
3. 转换正文为 Markdown，按出现顺序下载本地图片并替换为 Obsidian 嵌入。
4. 遇到“（完）”“全文完”等明确结束标记时，在该处结束；排除其后的往期推荐、广告和视频卡片。
5. 正文中的主文章视频才作为内容媒体；结束标记后的推荐视频不保存。
6. 网页 HTML 经常不含点赞、评论、收藏和分享数。无法读取时标记缺失，不推断、不填零。

常见失败：微信验证页、文章删除、仅登录可见、正文由特殊组件动态加载。可在用户已登录浏览器中读取；仍无法访问时，请用户导出或复制全文。

## OCR 与转写判断

- 有完整字幕：保留语音文字；画面 OCR 只补充表格、参数、步骤等增量信息。
- 无字幕、有音频：语音识别后去时间戳并分段。
- 图文：逐图 OCR 后人工/视觉复核，删除乱码、水印和重复车名。
- 公众号：正文文字优先；OCR 只补正文没有表达的图表或海报信息。

任何 OCR 或转写都可能存在错字。需要高准确度时保留原始字幕或 OCR 原稿到附件，并在主笔记标注来源与校对状态。
